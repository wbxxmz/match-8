# 设计说明：题二正向运动学 / 题三 Isaac 触碰

题二对应官方要求见比赛仓库 `README.md` 2.3 节，题三对应 2.4 节。本文只讲实现与验证，运行命令见 `README.md`。第 1~7 节是题二，第 8 节是题三。

## 1. 任务

1. 由完整 `joint_state`（10 关节）求 `objects_link` 在 `base_footprint` 中的位姿；
2. 把场景物体在 `base_footprint` 中的位姿变换到 `objects_link`。

输出同时给 `xyz`、`rpy`、`quat_xyzw`，四元数顺序 `[x, y, z, w]`。

## 2. 坐标系与约定

- `base_footprint`：底盘坐标系，链的根；
- `objects_link`：夹爪抓取参考点，`object_joint` 的子连杆；
- `rpy`：roll、pitch、yaw，对应 `R = Rz(yaw) · Ry(pitch) · Rx(roll)`；
- 位置单位米，角度单位弧度；四元数统一取正半球（`w ≥ 0`）。

## 3. 关节链

官方 xacro 展开后，从底盘到夹爪的链为：

```
base_footprint
└── base_joint         fixed      z +0.07          → base_link
    └── lift_base_joint        fixed      z +0.095         → lift_base_link
        └── lift_joint         prismatic  轴 z，origin (-0.019149, 0.099485, 0.1) → lift_link
            ├── arm_base_joint   fixed     rpy y = 1.5708    → arm_base_link
            │   ├── joint1  revolute  axis (1,0,0)   → arm1_link
            │   ├── joint2  revolute  axis (0,-1,0)  → arm2_link
            │   ├── joint3  revolute  axis (0,1,0)   → arm3_link
            │   ├── joint4  revolute  axis (1,0,0)   → arm4_link
            │   ├── joint5  revolute  axis (0,-1,0)  → arm5_link
            │   └── joint6  revolute  axis (0,0,1)   → arm6_link
            │       └── gripper_joint fixed z +0.0735 → gripper_link
            │           └── object_joint fixed z +0.12236, rpy y = -1.57
            │               └── objects_link
            └── pitch_joint  revolute  axis (0,-1,0) → head_pitch_link（不在通往夹爪的链上）
```

`arm_finger_joint1/2` 是 `gripper_link` 的子关节（轴向 `0 0 ±1`），同样不在 `objects_link` 的祖先链上。

程序不硬编码上表数值：`urdf_chain.py` 展开 xacro 后读取每个关节的 `<origin>` 与 `<axis>`，再沿 parent 指针上溯建链。`pitch_joint`、两个手指关节不在链上，但输入仍按题面要求校验完整 10 关节。

## 4. 数学

单个关节的变换：

```
T = Translate(xyz) · Rz(rpy[2]) · Ry(rpy[1]) · Rx(rpy[0])
转动关节：T = T · Rot(axis, q)
移动关节：T = T · Translate(axis · q)      # lift_joint 单位为米
固定关节：只乘 origin
```

链式累乘从 `base_footprint` 一路左乘到 `objects_link`。

逆变换不做数值求逆，直接用刚体性质：

```
R' = Rᵀ
t' = -Rᵀ t
```

`scene_object_in_objects_link = T⁻¹(base←objects) · T(base←scene)`。

`rpy` 用 `atan2` 按 Z-Y-X 反解；四元数用分支法从旋转矩阵求得，归一化后统一符号。

## 8. 题三设计：在 Isaac Sim 中触碰三个玩具

### 8.1 任务拆解

输入给每个测例一组 10 关节初值、底盘世界位姿、玩具世界位姿与玩具名。要求控制机械臂触碰玩具，输出最终关节状态和夹爪位姿，并报告玩具在夹爪参考系中的位姿。物理仿真、碰撞与关节执行由 Isaac Sim 负责，本作品只做目标位姿求解与关节目标序列。

### 8.2 与题二的分工

题二已验证 `base_footprint → objects_link` 的 URDF 链与正运动学。题三直接复用：

| 复用项 | 来源 |
| --- | --- |
| 展开官方 xacro、抽链 | `question2_project/urdf_chain.py` |
| 链式正解 | `question2_project/fk.py` |
| rpy / 四元数 / 齐次变换 | `question2_project/transforms.py` |
| 关节限位 | `question1_project/config/joint_limits.json` |

`planner.py` 只在此基础上补三件事：世界系到底盘系的换算、阻尼最小二乘逆运动学、缺关节时的链内补齐（`pitch_joint` 与两指不在 `objects_link` 链上，IK 迭代时取固定值，不影响该链正解）。

### 8.3 逆运动学

可动自由度 7 个（`lift_joint` + `joint1~6`）。误差向量为 6 维：位置 3 维 + 0.3×姿态 3 维；姿态误差用旋转矩阵的轴角公式（`log(target @ current.T)`），在 180° 附近不会像反对称近似那样归零——早期版本正因此把手腕反了的解当成已对准，画面就是“关节扭反、斜着抓”；雅可比取误差向量的数值差分（每列 1e-5 弧度），阻尼最小二乘每步更新，步长上限 0.2 弧度，位置收敛阈值 0.1 毫米、姿态 1 毫弧度，并优先选不穿地的解。

目标姿态按 `objects_link` 的真实坐标口径构造：**+X 是接近方向**（从手腕指向指尖）、+Y 是两指张开方向、+Z 是手指转轴。魔方与软玩具竖直朝下（+X = 世界 -Z），两指张到 0.5 弧度，掌部参考点分别停在中心上方 5 毫米 / 20 毫米；魔方两指沿底盘 x 轴贴合侧面，软玩具两指沿 y 轴、两片指面贴在脸的两颊上，从左右夹住正脸再合拢。恐龙资产自带 `xformOp:rotateXYZ=(0, 0, -90)`，题面输入给的是 `rpy=[0,0,0]`，所以每个测例开始时先把目标玩具刚体设成输入的世界位姿（位置 + 朝向）并等物理收敛 0.5 秒；摆正后恐龙是 23 厘米的长条，用竖直侧抱：+X 朝下、+Y 沿短轴（6.6 厘米），掌部参考点停在中心上方 2 厘米再合拢。底座角按目标方位角构造“面向目标”的伸手初值（`joint2≈0.15`、`joint3≈1.15`、`joint5≈-1.2`），另加 ±0.35、±0.7 弧度四个扰动与官方起点兜底；残差合格（位置 ≤1 毫米、姿态 ≤5 毫弧度）且不穿地的候选里取最接近标称姿态的解。

### 8.4 控制流程

| 步骤 | 内容 | 物理步数 |
| --- | --- | --- |
| 锁定底盘 | 初始化后记下底盘世界位姿，每个物理步后写回（该版本无 `fixRootJoint`） | 全程 |
| 摆正玩具 | 把目标玩具刚体设成题面输入的世界位姿（位置 + 朝向），等物理收敛；读回打印位置差与偏航差 | 30 |
| 置初值 | `set_joint_positions` + 目标同步，读回打印误差 | 40 |
| 抬升并转向 | 一段插值到 IK 求的转运姿态：玩具方位、半径 0.40 米、高 0.30 米（两指保持合拢） | 100 帧 × 2 |
| 下降到预抓取 | 玩具上方 0.15 米 | 90 帧 × 2 |
| 等待到位 | 保持预抓取目标，直到夹爪实际位置误差 < 2 厘米（最多 240 帧） | 视情况 |
| 下降到玩具 | 宽抓/侧抱：插值到中心上方 5 / 20 / 20 毫米，同时监测距离回升与指力矩 | 120 帧 × 2 |
| 保持等待 | 稳定 20 帧，等关节走到位 | 视情况 |
| 合拢两指 | 从 0.5 弧度合到 0，力矩超过阈值即停 | ≤90 帧 × 2 |

测例之间还有一段过渡（不占用任何一个测例的判据）：

| 过渡步骤 | 内容 | 物理步数 |
| --- | --- | --- |
| 带玩具微抬 | 升降在原位抬 2 厘米，让指尖沿玩具侧面脱开 | 20 帧 × 2 |
| 松指 | 两指张到 0.5 弧度，停一拍等玩具落稳 | 40 帧 × 2 + 10 帧 × 2 |
| 抬到转运高度 | 只动升降到 0.30 米，不做横移（低位横移会扫到桌面玩具） | 40 帧 × 2 |
| 高位插姿态 | 在 0.30 米把 10 关节平滑插值到下一例初值 | 70 帧 × 2 |
| 单独下降 | 姿态到位后再把升降降到初值 | 30 帧 × 2 |
| 驱动收敛 | 保持目标等物理跟上，最多 40 帧 | 视情况 |
| 分帧补齐 | 把剩余跟随静差按 smoothstep 分 30 帧硬插到位，避免下一帧 `teleport` 跳变 | 30 帧 × 2 |

过渡期间接触记录暂停（过渡动作不属于任何测例），结束后打印三个玩具的位移作为“有没有碰动”的证据。原来每例开头直接 `teleport` 到初值，视频里第二、三例开头各出现一次孤立跳变；改成上述连续动作后，切换点帧差与普通运动帧同量级。

每帧用 smoothstep 缓动，起停速度为 0，避免阶跃目标造成冲击。转运姿态放在 0.30 米高、玩具方位上：折叠状态下转底座，前臂会从立柱和底盘里扫过去；在玩具高度（十几厘米）上转，前臂又会把地面上三个玩具扫飞（实测软玩具被推 6 厘米，随后下降找不到玩具）。抬升与转向合成一段而不是“先举高再平移”，画面是连续的斜向上伸手；0.30 米低于最早的 0.45 米保守值，但已高于最高玩具（约 0.2 米）。下降结束后再保持 60 帧，等关节真正走到抓取点，避免“目标已下发、机械臂还在半路”被误判失败。

### 8.5 触碰判据

`objects_link` 距 `gripper_link`（法兰盘）0.12236 米，位于两指末端、靠近指尖的抓取参考点。它到玩具中心的距离与玩具自身尺寸同量级，因此距离本身不能证明接触。程序同时记录：

1. **触底回升**：距离进入 6 厘米后，下降中距离比历史最优回升 3 毫米，说明指尖压住玩具、臂被挡住（宽抓/侧抱下降时的兜底判据）；
2. **指关节力矩**：合拢两指被挡，力矩超过 0.15 N·m；
3. **玩具位移**：玩具被推离原位超过 5 毫米，只有机器人能造成；
4. **PhysX 接触报告**：给机器人各连杆与三个玩具挂 `PhysxContactReportAPI`（阈值 0），订阅仿真器的接触事件，分离 ≤ 1 毫米、冲量 > 1e-6 N·s 的真实碰撞对才算数。

任一满足即判定触碰；距离不再是判 PASS 的条件，只作为几何参考打印。三个玩具都是两指从左右两侧包住再合拢，第 2 项是主要证据：实测 0.276 / 0.676 / 0.651 N·m，玩具位移 0.7 / 0.3 / 4.2 毫米；下降途中指力矩超过 0.15 N·m 也立即停止，避免继续下压把玩具推走。前三项是间接推断，第 4 项是仿真器给出的硬证据：日志同时打印碰撞对（哪个连杆碰到哪个玩具）、分离距离与冲量，并检查是否碰到目标以外的玩具。第 1 项“回升”只在距离已进入 6 厘米后生效：下降初段手腕转动会让 `objects_link` 先向外摆几毫米，远处回升不是接触。距离只作几何参考，上限取 3 厘米与玩具包围盒半对角线的较大者（魔方 5.8 厘米 → 5.02 厘米），魔方最终距离 0.0046 米，远低于该上限。

### 8.7 已知局限

- PhysX 的接触摩擦与穿透让重跑数值小幅浮动，判据用阈值而非固定值；v16 本次 headless 为魔方 0.0046 米、恐龙 0.0194 米、软玩具 0.0196 米，更早的斜抓/反手方案是 0.004~0.026 米。差异主要来自“首次达到力矩阈值就停”的位置不同，都满足判据，且每次都有 PhysX 接触对上报。
- 只做“触碰”，不做抓取搬运；合拢两指是让两指真正夹住玩具，魔方、恐龙、软玩具都停在原位附近，不抬起。恐龙位移 0.3 毫米、偏航 -0.2°；软玩具位移 4.2 毫米、偏航 +0.5°，是两指夹住两颊时把轻质玩具带了一点。
- 魔方是 5.8 厘米的刚性方块，用竖直宽抓：两指沿 x 张到 0.5 弧度、贴合方块侧面，掌部参考点停在中心上方 5 毫米再合拢。最终距离 0.0046 米，判定靠合拢时的 0.276 N·m 指力矩，位置只移动 0.7 毫米、偏航 -0.1°。`objects_link` 位于两指末端、靠近指尖，距法兰盘 12 厘米，距离本身不能单独作为证据。
- 底盘锁定是“每步把根位姿写回”的近似，不是物理固定关节；根速度未清零，重跑仍可能有亚毫米级漂移（实测 0.0000 米）。
- 官方场景关闭了自碰撞，视觉上仍可能出现连杆互穿：输入给定的停车姿态本身就是折叠的，置初值那几秒无法避免；最近的那个软玩具需要把手臂伸到立柱旁，肘部与立柱在画面上靠得很近。
- 转运高度 0.30 米是观感与安全的折中；抬升段仍会让手臂升到画面上部，视频相机已拉远抬高以尽量带全，但手腕有时会贴到画面上边缘。
- GUI 运行与 headless 使用相同的物理步长与关节目标，差异只来自渲染节拍；摆正玩具与恐龙侧抱改动后未再单独做 GUI 对照，正式数值以 headless 为准。此前宽抓方案 GUI/headless 的距离最大差 0.3 毫米、峰值力矩最大差 0.198 N·m（恐龙，判据阈值 0.15 N·m 仍满足）、玩具位移最大差 1.4 毫米，接触判定三例一致。曾遇到一次图形模式启动后关节目标未被接管、机械臂完全不动（初值读回差 0.29 rad），同机重启 Isaac 后复现为 PASS，属启动阶段的偶发现象，重跑即可。曾在 GUI 下因“远处回升”被误判接触而停在 0.15 米，已修复（回升判据限定在 6 厘米内，见 H71）；转底座帧数不足时关节跟不上、下降会在半路结束，也已加长并补“保持等待”。
- 图形模式跑完默认保持窗口 90 秒（`--hold-sec` 可调），这是为了看清最后一个玩具的最终姿态；无窗口模式保持 0 秒。
- 未使用 ROS 2 话题收发，控制走 `Articulation` 接口；Bridge 仍需启用，否则场景自带的 OmniGraph 节点会报错。

### 8.8 自检

`python3 src/question3_project/verify_q3.py` 不依赖 Isaac Sim，只读答案、输入、日志与视频，检查：答案行数与 id 对应、10 关节齐全且在限位内、用最终关节重算 FK 与答案位姿一致、玩具位姿逆变换闭环（主字段允许“玩具位移 + 2 毫米”）、按输入位姿算的那一份严格闭环（位置与旋转容差 2 毫米，底盘实测与标称差约 0.8 毫米）、三例接触证据成立、日志三次 PASS 且无 error/warning、视频存在。同时做环境预检：Python/numpy 版本、官方 URDF 关节链、场景文件、Isaac `python.sh`，缺场景或 Isaac 只提示 WARN，不阻断离线校验。

`python3 -m pytest src/question3_project/tests -q` 是规划回归测试（22 项）：链顺序与完整 10 关节校验、底盘/objects_link/玩具位姿变换闭环、答案与最终关节 FK 一致、三个玩具中心的 IK 残差（位置 < 0.1 毫米、姿态 < 1 mrad）、答案关节限位，以及一组与 demo 不同的初值（升降 0.08 米、肘部展开）的 FK 有限性与地面检查。
